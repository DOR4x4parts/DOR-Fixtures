# DOR Fixtures website

Current website concept for **DOR Fixtures**, a trading name of Danells Off-Road Ltd.

## Launch product

- 1000 × 2000 mm DIY welding fixture table
- S275 mild steel
- Main table structure: 6 mm plate
- Top plate options: 6 mm or 8 mm S275

## Current site status

The site is front-end only at this stage and is suitable for static hosting such as Cloudflare Pages.

Shopify product and checkout integration can be added once pricing, hole pattern, table height/base design and delivery format are confirmed.

## Files

- `index.html` — homepage
- `styles.css` — styling and responsive layout
- `script.js` — mobile navigation, reveal effects and prototype form behaviour
